# Estado de Internacionalización (i18n) — @farutech/design-system v1.0.1-rc

## Estado Actual: Spanish Default Hardcoded
En la versión `1.0.1-rc`, todos los textos internos y mensajes de estado del Design System están configurados con literales por defecto en **Español (es-CO / es-LA)**.

La parametrización dinámica mediante `LocaleContext` y diccionarios extensibles en `DesignSystemProvider` está programada para la versión **`1.1.0`**.

## Roadmap de Parametrización en v1.1.0
Para `v1.1.0`, `DesignSystemProvider` incorporará:
```tsx
<DesignSystemProvider
  locale="es" // 'es' | 'en' | 'pt' | custom
  messages={{
    dataTable: {
      searchPlaceholder: "Search records...",
      emptyMessage: "No data available",
    }
  }}
>
```
Cualquier consumidor con requerimientos multilingües previos a `1.1.0` puede sobrescribir los textos a través de las props declarativas de cada componente (`placeholder`, `emptyMessage`, `loadingMessage`, `label`).
