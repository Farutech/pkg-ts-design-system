# 📦 Instalación y Configuración

Guía paso a paso para integrar y configurar `@farutech/design-system` en cualquier proyecto React con TypeScript.

---

## 1. Instalar la librería

```bash
# Usando npm
npm install @farutech/design-system

# Usando pnpm
pnpm add @farutech/design-system

# Usando yarn
yarn add @farutech/design-system
```

**Dependencias requeridas (Peer Dependencies):**

```bash
npm install react@^18.0.0 || ^19.0.0 react-dom@^18.0.0 || ^19.0.0
```

---

## 2. Configurar Tailwind CSS

Si tu proyecto utiliza Tailwind CSS, extiende la configuración agregando los tokens oficiales y las rutas de los componentes:

```js
// tailwind.config.js
import { farutechPreset } from "@farutech/design-system/tokens"

export default {
  content: [
    "./src/**/*.{ts,tsx}",
    // Incluir rutas compiladas de la librería
    "./node_modules/@farutech/design-system/dist/**/*.{js,mjs}",
  ],
  presets: [farutechPreset], // Tokens corporativos, paleta HSL y radios
}
```

---

## 3. Importar los estilos base

En el punto de entrada de la aplicación (`main.tsx` o `index.tsx`):

```tsx
// main.tsx
import React from "react"
import { createRoot } from "react-dom/client"
import "@farutech/design-system/styles.css"
import { DesignSystemProvider } from "@farutech/design-system"
import App from "./App"

createRoot(document.getElementById("root")!).render(
  <React.StrictMode>
    <DesignSystemProvider colorMode="dark">
      <App />
    </DesignSystemProvider>
  </React.StrictMode>
)
```

---

## 4. Importar componentes

```tsx
// Importación principal (Recomendada)
import {
  Button,
  Badge,
  DataTable,
  CrudPagination,
  Modal,
  Input,
  FloatingInput
} from "@farutech/design-system"

// O mediante subpaths para optimización extrema de bundles:
import { Button } from "@farutech/design-system/components/ui"
import { CrudPagination } from "@farutech/design-system/components/crud"
import { Sidebar, Navbar } from "@farutech/design-system/components/layout"
```

---

## 5. Theming y Modo Oscuro (Dark Mode)

El sistema de diseño incluye soporte nativo para temas claro y oscuro:

### Opción A — Atributo HTML
```tsx
document.documentElement.setAttribute("data-theme", "dark")
```

### Opción B — Provider reactivo
```tsx
<DesignSystemProvider colorMode="dark">
  <App />
</DesignSystemProvider>
```

---

## 6. Configuración de Storybook para Pruebas Visuales

Para habilitar pruebas visuales con Chromatic en tu equipo:
1. Agrega tu token de proyecto en secrets de GitHub: `CHROMATIC_PROJECT_TOKEN`.
2. El workflow `.github/workflows/chromatic.yml` se encargará de ejecutar las pruebas de regresión visual y publicar Storybook automáticamente.
