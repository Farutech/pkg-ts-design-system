## 🎨 Storybook & Herramientas de Desarrollo

El entorno de Storybook está configurado para ofrecer una experiencia interactiva completa:

### 1. Control dinámico con Controls
Cada historia expone sus propiedades mediante el panel de **Controls**. Puedes modificar variantes, tamaños, colores, estados (deshabilitado, cargando) y textos en tiempo real para verificar el comportamiento del componente.

### 2. Responsividad con Viewports
Verifica el diseño adaptativo seleccionando la resolución deseada en la barra superior de Storybook:
- **Mobile (Small)**: 375px × 667px
- **Mobile (Large)**: 414px × 896px
- **Tablet (iPad)**: 768px × 1024px
- **Laptop**: 1280px × 800px
- **Desktop**: 1440px × 900px

### 3. Pruebas Visuales con Chromatic (`@chromatic-com/storybook`)
Integrado directamente en Storybook mediante el addon de **Visual Tests**:
- Captura snapshots automáticos en múltiples navegadores y viewports.
- Detecta regresiones visuales antes de que lleguen a producción.
- Permite publicar Storybook para revisión y feedback colaborativo del equipo.

### 4. Automatización en CI
El flujo `.github/workflows/chromatic.yml` ejecuta las pruebas visuales en cada Pull Request y publica la versión actualizada de Storybook para revisión del equipo.

## 📦 Instalación Rápida / Quick Start

```bash
# Instalación del paquete
npm install @farutech/design-system

# Dependencias requeridas
npm install react react-dom
```

### Configuración en la aplicación / Application Setup

```tsx
// main.tsx o App.tsx
import React from "react"
import ReactDOM from "react-dom/client"
import "@farutech/design-system/styles.css"
import { DesignSystemProvider } from "@farutech/design-system"
import App from "./App"

ReactDOM.createRoot(document.getElementById("root")!).render(
  <React.StrictMode>
    <DesignSystemProvider colorMode="dark">
      <App />
    </DesignSystemProvider>
  </React.StrictMode>
)
```

## 🛡️ Principios de Diseño

1. **Alto Contraste y Accesibilidad (WCAG AA)**: Colores y tipografías optimizados para entornos oscuros y claros con legibilidad impecable.
2. **Consistencia Visual**: Espaciados, radios de borde y sombras basados en la escala oficial de FaruTech.
3. **Ergonomía de Operación**: Menús compactos, tablas densas pero legibles y navegación fluida para sistemas de alta demanda operativa.
