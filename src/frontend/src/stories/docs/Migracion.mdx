# 🔄 Guía de Migración

Historial de cambios importantes, mejoras arquitecturales y pasos de migración entre versiones de `@farutech/design-system`.

---

## v1.1.0 → v1.2.0

### ✨ Novedades y Mejoras

- **CrudPagination**: Nuevo paginador balanceado de tres columnas con selector dinámico de registros por página (`perPageOptions`), navegación con teclado, botones numéricos inteligentes y salto directo (`showJumpToPage`).
- **Storybook 10 & Visual Testing**: Incorporación de `@chromatic-com/storybook` para pruebas de regresión visual y publicación automatizada de Storybook para feedback del equipo.
- **Controles y Viewports**: Todas las historias de componentes soportan manipulación interactiva de propiedades mediante Controls y previsualización responsive en múltiples Viewports (Mobile Small, Mobile Large, Tablet, Laptop, Desktop).
- **TopNav & Layouts**: Mejor soporte para layouts de catálogos y paneles administrativos densos.

### 🔧 Compatibilidad de API

La API pública mantiene retrocompatibilidad total:
```tsx
import { CrudPagination, DEFAULT_PER_PAGE_OPTIONS } from "@farutech/design-system"
```

---

## v1.0.x → v1.1.0

### Breaking Changes

#### DataTable: prop `columns` renombrada

```tsx
// Antes (v1.0.x)
<DataTable cols={columns} data={data} />

// Ahora (v1.1.0+)
<DataTable columns={columns} data={data} />
```

#### Tokens CSS: prefijo oficial `--ft-`

```css
/* Antes (v1.0.x) */
--ds-color-primary: #2563eb;

/* Ahora (v1.1.0+) */
--ft-color-primary: #6366f1;
```
